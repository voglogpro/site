# Решения продукта

## Четыре понятных раздела

Нижнее меню разделяет разные задачи: карта маршрута, партнёры и их акции, личный квест с наградами, профиль с правилами и поддержкой. Текущая вкладка всегда выделена, а прогресс виден без поиска по экранам.

## QR и необязательная геопроверка

Физический QR у стойки — основной способ поставить штамп. `SCAN_REQUIRE_GEO=1` может дополнительно потребовать разовую координату рядом с точкой; она проверяется в запросе и не сохраняется. По умолчанию геопозиция нужна только для локальной сортировки точек и маршрута.

## Геопозиция без слежки

Live Location не используется. Mini App запрашивает позицию только после явного нажатия, рассчитывает расстояния на телефоне и забывает координату после закрытия. Внешнему навигатору передаются координаты выбранной точки; начало маршрута он определяет сам.

## Награды

Локальные коды генерируются идемпотентно после подтверждения точки. Завершение открывает Premium, но в очередь CRM попадают только участники, которые явно нажали «Получить Premium». Заявка идемпотентна, отправляется в чат поддержки и остаётся `pending`, пока компания реально не выдаст Premium. Интерфейс не пишет «подписка активирована», пока администратор не подтвердил выдачу.

## Безопасность поездки

Перед маршрутом и QR интерфейс напоминает полностью остановиться. В приложении нет механик, побуждающих смотреть в экран во время движения.

## Данные и безопасность

- пользователь определяется только по проверенному `initData`, не по ID из JSON;
- CRM защищена паролем `ADMIN_PASSWORD` и подписанной HttpOnly-сессией; Telegram ID для входа не нужен;
- QR хранится как HMAC digest, сырой код показывается только сразу после ротации;
- записи и выдача выполняются в коротких `BEGIN IMMEDIATE` транзакциях;
- у сессии один снимок трёх точек;
- повторы API и Telegram update не создают повторную награду;
- разовая координата пользователя не записывается в рабочую базу;
- рабочая база находится только в постоянном каталоге BotHost.

## Визуальное направление

«Тёмный маршрут по Поляне»: фон `#07110B`, фирменный зелёный `#2BC24A`, крупная outdoor-типографика, карточки с радиусом не больше 16 px. Маскот не используется как постоянный декор. На кнопках нет градиентов; анимация ограничена сменой состояния и выдачей награды.
