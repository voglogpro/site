# BibiBike Quest — Красная Поляна

Отдельный Telegram-бот с Mini App для квеста по трём партнёрским точкам. Участник выбирает места в любом порядке, открывает маршрут в Яндекс Картах или 2ГИС, подтверждает визит физическим QR и получает подарок. После трёх уникальных точек система создаёт одну заявку на месяц Premium bb.bike.

Проект изолирован от рабочих ботов сотрудников и исполнителей и использует отдельный токен и SQLite-базу.

## Что реализовано

- мобильный Mini App «Паспорт долины»: маршрутный экран, реальные QR-штампы, сохранённые промокоды и заполненный паспорт;
- свободный порядок прохождения: можно начать с любой точки;
- кнопка «Показать ближайшие» делает разовый расчёт только на телефоне и не отправляет координату боту;
- маршруты от текущего положения через Яндекс Карты и 2ГИС: Бибибайк, пешком или автомобиль;
- QR-сканер Telegram и ручной резервный код;
- сохранённые подарки, прогресс `0/3 → 3/3`, яркий экран награды и Premium;
- серверная HMAC-проверка `Telegram.WebApp.initData`;
- защита от повторной выдачи и атомарное создание одной финальной награды;
- совместимая миграция старой базы: участники, прогресс и действующие QR сохраняются;
- адаптивная CRM с воронкой, участниками, Premium и статистикой использования;
- несколько QR на одну точку: название, включение/отключение, ручной код, число сканов;
- CRM-карта по умолчанию заблокирована от случайного сдвига, ограничена зоной Красной Поляны, координаты подтверждаются только кнопкой сохранения;
- `/health` и `/ready` для BotHost.

## Важное решение по геолокации

Live Location удалён. Бот не принимает и не хранит трансляцию маршрута. Геопозиция используется только по явному нажатию «Показать ближайшие», расстояния рассчитываются локально в Mini App, а координата исчезает после закрытия страницы. Навигатор получает только координаты выбранного места и сам определяет начало маршрута.

Статический QR можно сфотографировать и переслать. Для дорогих наград рекомендуется динамический QR, одноразовый код сотрудника партнёра или проверка активной аренды через API bb.bike. Текущий QR-only сценарий оптимизирован для простого пилота.

## До реального запуска

Демо-кампания изначально выключена. В CRM нужно заменить все три точки реальными данными:

1. название и адрес партнёра;
2. координаты внутри Красной Поляны;
3. часы работы;
4. условия подарка;
5. один или несколько физических QR;
6. процесс выдачи Premium.

## BotHost

Обязательные переменные окружения:

```text
BOT_TOKEN=...
WEBAPP_URL=https://ваш-домен.bothost.tech
ADMIN_IDS=7785586524
QR_SECRET=случайная-строка-не-короче-32-символов
DATA_DIR=/app/data
WEB_PORT=3000
TIMEZONE=Europe/Moscow
```

Команда запуска: `python main.py`. В BotFather URL Mini App должен совпадать с `WEBAPP_URL`. Рабочую `.db` нельзя хранить в GitHub; для `/app/data` нужен постоянный том.

## Проверка

```powershell
python -m compileall -q main.py quest scripts
python scripts/smoke_check.py
```

Smoke-тест проверяет чистую БД, миграцию v2, все шесть вариантов порядка трёх точек, повтор QR и единственную выдачу Premium.

## Структура

```text
main.py                 запуск polling и aiohttp
quest/config.py         настройки окружения
quest/db.py             SQLite, WAL и совместимые миграции
quest/security.py       Telegram HMAC и QR digest
quest/service.py        свободный прогресс, QR, награды, CRM-аналитика
quest/api.py            Mini App и admin API
quest/bot.py            команды и кнопки Telegram
index.html              Mini App участника
static/admin.html       CRM администратора
static/app.css          общая дизайн-система
static/privacy.html     простое объяснение данных
```

Пользовательская карта удалена. В служебной CRM используются стандартные тайлы OpenStreetMap с обязательной видимой атрибуцией `© OpenStreetMap`; префикс Leaflet и его значок не показываются.
