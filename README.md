# BibiBike Quest — Красная Поляна

Отдельный Telegram-бот с Mini App для маршрута из трёх партнёрских точек. Участник включает Live Location, посещает точки по порядку, подтверждает каждую физическим QR и получает локальные подарки. После третьей точки система создаёт заявку на месяц премиума bb.bike.

Проект изолирован от рабочих ботов сотрудников и исполнителей. Он использует отдельный токен и отдельную SQLite-базу.

## Что уже реализовано

- мобильный Mini App в фирменном зелёном дизайне с реальной картой, маршрутом `0/3 → 3/3`, расстояниями, сохранёнными подарками и финалом;
- тёмно-зелёная карта с точками, синим маркером текущего гео и выбором маршрута: Бибибайк, пешком или автомобиль;
- честная инструкция по включению Telegram Live Location;
- обработка первого сообщения с геопозицией и последующих `edited_message`;
- геозона с настраиваемым радиусом, по умолчанию 100 м;
- двойное подтверждение точки: попадание в радиус + QR партнёра, в любом порядке;
- строгий порядок точек и сохранение прогресса при перезапуске;
- серверная HMAC-проверка `Telegram.WebApp.initData` и ограничение срока подписи;
- защита от повторной выдачи, неверного QR, очень плохой точности и очевидных GPS-скачков;
- адаптивная CRM: карта с перетаскиванием точек, редактор наград, воронка этапов, участники, QR и CSV завершивших;
- снимок маршрута на старте: правка админом не меняет путь уже едущего участника;
- журнал административных изменений;
- автоматическое удаление точных координат завершённых сессий;
- `/health` и `/ready` для BotHost.

## До реального запуска нужны данные заказчика

Приложение намеренно создаёт **выключенный демо-маршрут**. В нём нельзя запустить квест, пока администратор не заменит все три точки реальными данными:

1. название партнёра;
2. адрес, широта и долгота;
3. часы работы;
4. точная скидка и инструкция выдачи;
5. физический QR, созданный в CRM;
6. понятный процесс выдачи premium: автоматический API, промокод или ручная обработка CSV.

Так система не обещает пользователю несуществующую скидку или автоматическую подписку.

## Запуск на BotHost

1. Создайте отдельного бота через BotFather и отдельный репозиторий.
2. Скопируйте `.env.example` в переменные окружения BotHost.
3. Обязательно задайте:
   - `BOT_TOKEN`;
   - `WEBAPP_URL=https://ваш-домен.bothost.tech`;
   - `ADMIN_IDS` — Telegram ID администраторов через запятую;
   - `QR_SECRET` — случайная строка минимум 32 символа;
   - `DATA_DIR=/app/data`;
   - `WEB_PORT=3000` или выделенный хостингом порт.
   - при необходимости `MAP_TILE_URL` и `MAP_ATTRIBUTION` для выбранного поставщика карт.
4. Подключите постоянный том `/app/data`. Рабочую `.db` нельзя хранить в GitHub.
5. Команда запуска: `python main.py`.
6. В BotFather укажите Mini App URL, равный `WEBAPP_URL`.
7. Откройте `/admin` в личном чате, заполните три точки, обновите QR и выполните реальный тест маршрута.
8. Только после теста переведите кампанию из «Черновика» в «Активен».

## Локальная проверка

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
$env:DEV_MODE="1"
$env:DATA_DIR="$PWD\data"
python main.py
```

Для полноценного polling нужен настоящий `BOT_TOKEN`. Серверные компоненты без Telegram проверяются командой:

```powershell
python scripts/smoke_check.py
```

## Как подтверждается точка

1. Live Location или свежая координата Mini App попадает в радиус точки.
2. Пользователь сканирует QR у партнёра или вводит код вручную.
3. Оба факта сохраняются независимо и не исчезают из-за плохой сети.
4. После двух фактов сервер атомарно завершает точку и выдаёт один код подарка.
5. После третьей точки создаётся единственная заявка на premium.

Статический QR можно сфотографировать и переслать, поэтому он никогда не принимается без геозоны. Для следующего уровня защиты можно добавить динамические QR партнёров, но это требует отдельного оборудования или кабинета партнёра.

## Приватность

Mini App заранее объясняет использование геолокации и просит согласие. Партнёры не видят маршрут. По умолчанию точные наблюдения завершённых и истёкших сессий удаляются через 7 дней. CSV содержит только данные, нужные для выдачи premium, без координат.

## Структура

```text
main.py                 запуск bot polling и aiohttp
quest/config.py         переменные окружения
quest/db.py             схема SQLite и транзакции
quest/security.py       Telegram HMAC и QR digest
quest/service.py        состояния, геозона, QR, награды
quest/api.py            Mini App и admin API
quest/bot.py            команды и Live Location handlers
static/index.html       Mini App участника
static/admin.html       CRM администратора
static/app.css          единая дизайн-система
static/bb-bike-logo.jpg фирменный знак из предоставленного макета
static/vendor/          локально подключённая библиотека карты Leaflet
static/privacy.html     понятное уведомление о данных
```

По умолчанию используются стандартные тайлы OpenStreetMap с обязательной атрибуцией. Для коммерческой нагрузки настройте собственного поставщика тайлов: публичный сервер OpenStreetMap работает без SLA и не предназначен для массового офлайн-кеширования.

Подробные решения и ограничения: [docs/PRODUCT-DECISIONS.md](docs/PRODUCT-DECISIONS.md).
